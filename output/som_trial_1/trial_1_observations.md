# Card Type Sequence

The following sequence is a refinement of what was shipped this go around, but it does not necessarily address all the observations below.

1. Outline cloze
2. Current sub-unit outline cloze
3. leaf text -> header
4. missing words (new, discussed below)
5. first letter
6. scaffolded cloze
7. anchor cloze
8. leaf header -> text
9. missing sub-unit text cloze

# Observations

- More work needs to be done on the whole outline first; maybe not total recall
- More surrounding lines in outline and sub-unit clozes
- Questions need to be more visually prominent in leaf text -> header
- First letter cards look odd; I think they are good, but the letters need to be arranged so that they are at the same position they would be in if the full words were present; and perhaps put a dark blur over the remainder of the word to prompt memory of the hidden portions of the words
- When recitig the leaf text, it would be helpful to have the front of the card and even back of the card display that text's position in the outline
- I need to understand the learning steps more clearly; it appears that when encountering a new card, you usually always press 'again', since there would be no way for you to know that card yet if the material is truly new; is this why the first learning step is '1m'?
- To bridge difficulty gap between recalling entire verses and working on the outline, a missing word card type might be useful that covers every other word or every 2nd and 3rd word from the verse
- I did like the cloze of entire sub-units of text in the context of the surrounding sub-unit text
- I did like the later cards in each cycle that have you recall the entire outline

# Reflections

- The core task is to solidify the card type sequence that can be applied to any outline.
- Greater visibility of the structure of the text appears to be key. If the user can master the skeleton that the text is tied to, they will have an easier time understanding, navigating, and orienting themselves throughout the text memorization phases. Therefore, we may try leaning into full mastery of the outline before any verse text appears.
- As such, a well-designed custom HTML/CSS style for each card type will be both visually appealing but also support the mastering of the outline and verse material in its greater context.
- Each deck would therefore follow some sort of sequence not just of card types but of phases that work through the text's outline first, and then a set algorithm that works through the chunks of text, moving from leaves to trunk
- I researched what the Bible Memory app does; it focuses only on the text, no outline work; it uses the same 3 steps for every unit of text; step 1 is full text visible, type first letter; step 2 is every 2nd and 3rd word missing, type first letter of missing words; step 3 is no text visible, type first letter of each word; I think my focus on outlines is key because it promotes grasping the logical flow of the material, which enhances understanding, which in turn enhances recall; but I do think something can be said about user output, even if it's just mobile phone input, rather than silent guesses in the user's head; I am not sure if Anki can support a card type with buttons or enhances interactive input that allows this concept; audio input that tracks word matching would be best, but that may need to be in the next phase of the project
