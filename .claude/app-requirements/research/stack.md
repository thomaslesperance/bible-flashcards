# Research: stack

> Snapshot from 2026-10-14, written by Claude's research agents for the app spec (`../CLAUDE.md`). Each finding lists its sources and a confidence level. Recheck anything time-sensitive (versions, prices, store policies) before acting on it.

## Summary
As of 2026-10-14 the current stable release is Expo SDK 57 (released 2026-06-30). It ships React Native 0.86.3, React 19.2.3, Hermes V1 and the New Architecture only; the Legacy Architecture was dropped in SDK 55. SDK 58 (React Native 0.88 RC, React 19.3) has been in beta since 2026-09-15 and should go stable within weeks. It brings stable native tabs, the iOS 27 scene lifecycle and Android home-screen widgets through expo-widgets. Recommendation: start on SDK 57 now, upgrade to SDK 58 a few weeks after it goes stable, and always add native dependencies with `npx expo install`. The npm `latest` versions of Reanimated, worklets, Skia and TypeScript are ahead of what SDK 57 pins. Recommended stack: expo-router 57, expo-sqlite 57 with Drizzle 0.45.x (driver 'expo'; v1 is RC.5 with a new migration-folder format), Zustand 5 plus TanStack Query 5, and Uniwind (free, Tailwind v4, from the Unistyles team) with HeroUI Native 1.0.x as the "modern Bootstrap" layer. Unistyles 3.5 is the conservative fallback. NativeWind v5 is still RC (v4 latest), gluestack v5 depends on that RC, and Tamagui 3.0 shipped 4 days ago (10 patches since). The plant: @shopify/react-native-skia 2.6.2 (Expo-pinned) with Reanimated 4.5.1 and worklets 0.10.1, using path trim (start/end), Atlas sprites and UI-thread shared values. Skia has moved to William Candillon, and its v3 is renamed `react-native-skia`. iOS widgets and Live Activities: expo-widgets has been stable on iOS since SDK 56. Android widgets: react-native-android-widget now, or expo-widgets Android in SDK 58. Scheduling: ts-fsrs 5.4.2 (FSRS-6) on-device. The only TS-side optimizer (@open-spaced-repetition/binding 0.5.0) is Node/WASI public beta, so run optimization on Cloud Run or in Python (py-fsrs), not on-device. EAS Free covers this solo project: 15 iOS + 15 Android builds a month, 1,000 Update MAU, Submit included. Local `expo run:ios` builds on the Mac cost nothing. Auth: Firebase JS SDK 12.19 with expo-apple-authentication and google-signin is the lightest path. Apple 4.8 requires an equivalent privacy-preserving login (Sign in with Apple) if Google sign-in is offered, and 5.1.1(v) requires in-app account deletion. For AI screenshot loops, Claude Code Desktop's official iOS Simulator pane (public beta) plus Expo MCP local automation (screenshot, tap by testID) cover iOS. Android is covered by the Apple Silicon emulator (arm64 images), Firebase Test Lab Spark (10 virtual + 5 physical runs a day) and Play pre-launch reports.

- **[high]** expo-router 57.0.26 (versions now track the SDK major): file-based routing, typed routes, automatic deep links. In SDK 57, native tabs are imported from `expo-router/unstable-native-tabs`; the stable `expo-router/native-tabs` import arrives in SDK 58.
  - Native tabs limitations: Android max 5 tabs, tab bar height can't be measured, no runtime add/remove of tabs (remounts and loses state), limited FlatList integration, all tab screens render eagerly. On iOS 26 Liquid Glass ignores custom tab bar backgrounds. The default template uses native tabs and @expo/ui.

- **[high]** expo-sqlite ~57.0.4 provides sync and async APIs, SQLiteProvider/useSQLiteContext with Suspense, a tagged-template `db.sql` API, a change listener, the session extension (changesets), SQLCipher (config plugin), FTS3/4/5 on by default, sqlite-vec, an AsyncStorage-compatible `expo-sqlite/kv-store`, and a built-in dev inspector. Web support is alpha.
  - Expo's documented migration pattern is PRAGMA user_version in onInit. withTransactionAsync is NOT exclusive (unrelated async queries can leak in); use withExclusiveTransactionAsync for review writes (native only). The useLibSQL/syncLibSQL options are removed in SDK 58, so don't build sync on them.
  - sources: https://docs.expo.dev/versions/latest/sdk/sqlite/, https://expo.dev/changelog/sdk-58-beta

Bundle migrations with babel-plugin-inline-import for .sql plus 'sql' in Metro sourceExts, apply them with useMigrations(db, migrations) from drizzle-orm/expo-sqlite/migrator, and get reactive queries from useLiveQuery (open the DB with enableChangeListener: true). Triggers: DAILY/MONTHLY (iOS+Android), WEEKLY/YEARLY (Android; use CALENDAR on iOS), DATE and TIME_INTERVAL. A setNotificationHandler is required or notifications aren't shown. - **[high]** App Store guideline 4.8: an app that uses Google Sign-In to create or authenticate the primary account must also offer an equivalent login that limits data to name and email, lets users hide their email, and doesn't track for ads. In practice that is Sign in with Apple. Guideline 5.1.1(v) requires in-app account deletion, and apps that use Sign in with Apple should revoke the user's tokens via the Sign in with Apple REST API on deletion.

## gotchas
- npm `latest` doesn't match the Expo SDK pins. Reanimated is at 4.7.1, worklets 0.13.0, Skia 2.14.0 and TypeScript 7.0.2 on npm, but SDK 57 pins 4.5.1, 0.10.1, 2.6.2 and ~6.0.3. Agents running `pnpm add` will install mismatched native versions; always use `npx expo install` and `npx expo install --check`.
- TypeScript 7.0 (the Go-native compiler, released 2026-07) is npm `latest`, but Expo templates for both SDK 57 and 58 still pin ~6.0.3. Don't let tooling bump it.
- SDK 56's Hermes V1 memory regression with Reanimated/worklets is fixed only in expo@57.0.9+ (dev-startup fix in 57.0.17+), so don't start on SDK 56.
- React Native Skia was renamed: v3 is `react-native-skia` (Graphite, Android minSdk 26 + Vulkan, no Expo Go), and `@shopify/react-native-skia` stops at 2.14. Installing both packages breaks the build, and so does any library that imports the old name after you switch.
- Reanimated 4 needs the separate react-native-worklets package. Skia colors must be interpolated with Skia's interpolateColors, not Reanimated's interpolateColor.
- NativeWind v5 RC: `:root.dark` selectors throw, and the RC needs an exact react-native-css engine version (restart Metro after updates). gluestack v5 inherits this because it depends on NativeWind v5.
- expo-sqlite withTransactionAsync isn't exclusive: other async queries can run inside your transaction. Use withExclusiveTransactionAsync (native only).
- Drizzle's Expo docs now tell you to install @rc (v1), while npm `latest` is 0.45.4. The v1 migration-folder format differs (no journal.json; `drizzle-kit up` converts). Pick one deliberately and don't mix docs from the two versions.
- Migrations must be bundled into the app: you need the babel inline-import plugin for .sql files and 'sql' in Metro sourceExts, or migrations silently won't load.
- expo-widgets widget code can't use hooks, state, async, imports or module-scope values, so all data must be pushed from the app (updateSnapshot/updateTimeline) or read from the shared App Group directory.
- iOS keeps at most 64 pending local notifications. Calling removeAllPendingNotificationRequests elsewhere silently wipes reminders.
- Google Play only allows USE_EXACT_ALARM for alarm/timer and calendar apps; a Bible-memory app declaring it risks rejection.
- RNTL v14 made render/fireEvent/act async. Tests generated from older examples (sync render, UNSAFE_* queries, react-test-renderer) will fail; run the rntl-v14 codemods.
- getReactNativePersistence from firebase/auth has a recurring TypeScript 'no exported member' error even though it works at runtime. Expect a brief null user before onAuthStateChanged fires, so gate navigation on it.
- Sign in with Apple's getCredentialStateAsync always throws on the simulator, so SIWA has to be tested on Thomas's iPhone.
- Free google-signin uses Google's deprecated legacy Android Sign-In SDK, which Google may remove from Play Services.
- Claude Code Desktop simulator screenshots are sent to Anthropic. Use test accounts on agent-driven simulators, never real personal or church accounts.
- Expo MCP local automation is iOS-simulator-only on iOS (no physical devices), allows one dev-server connection at a time, and needs reconnecting whenever the dev server restarts. search_documentation needs a paid plan.
- The EAS Free plan has a 45-min build timeout, low-priority queue, 1 macOS concurrency and a hard 1,000 Update MAU cap. Maestro jobs on EAS Workflows are not included in Free.
- pnpm 11+ ignores nodeLinker/shamefullyHoist in .npmrc (they must move to pnpm-workspace.yaml), fails on unapproved postinstall builds unless listed in allowBuilds, and by default won't resolve packages published less than 1 day ago.
- Native tabs in SDK 57 are still `unstable-native-tabs`: max 5 tabs on Android, eager rendering, and Liquid Glass ignores custom tab bar background colors on iOS 26.
- Hermes WebAssembly support is only reported by secondary sources, so don't plan on running the WASI FSRS optimizer on-device.
